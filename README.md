A single pickup line, aimed at a robot or an AI — the setup and the punch land inside one 90-character line, and the laugh comes from the machine premise itself: the attention mechanism, not a battery or a reboot.

> Are you my attention mechanism? Because in a room full of tokens, I only ever look at you.

## Run it

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset). Before writing, the program gates the line: 1–200 characters, a single line with no stray whitespace, valid UTF-8 that survives a byte-for-byte round trip, and a repeat run must produce identical bytes.
